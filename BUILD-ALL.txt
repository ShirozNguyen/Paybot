PayBot v5.5.5 — Build TẤT CẢ jar (93 module) chỉ bằng 1 lệnh
====================================================================

Chạy đúng 1 lệnh này tại thư mục gốc project (nơi có file settings.gradle):

    gradlew build

(Trên macOS/Linux dùng: ./gradlew build)

Lệnh này sẽ tự động:
  1. Build lần lượt cả 93 module (39 Fabric + 37 Forge + 17 NeoForge + 1 Plugin)
  2. Sau khi build xong, tự copy toàn bộ jar vào:
     C:\Users\Administrator\Documents\Works\done\
       ├── Fabric_Quilt\    (39 file, mỗi bản MC 1 jar riêng)
       ├── Forge\           (37 file, mỗi bản MC 1 jar riêng)
       ├── NeoForge\        (17 file, mỗi bản MC 1 jar riêng)
       └── Plugins\         (1 file PayBot-Plugin-5.5.5.jar, chạy Paper/Purpur/Folia)

Lưu ý:
  - Lần build đầu tiên sẽ RẤT LÂU (Gradle phải tải riêng bộ Minecraft dependency
    cho từng bản trong số 93 bản — có thể mất hàng giờ, tuỳ tốc độ mạng).
  - Các lần build sau sẽ nhanh hơn nhiều nhờ cache.
  - Nếu 1 module lỗi (vd sai số hiệu fabric-api/neoforge ở các bản đã ghi chú
    "ước tính" trong gradle.properties), các module KHÁC vẫn build bình thường —
    chỉ cần sửa đúng 1 dòng version trong gradle.properties của module bị lỗi
    rồi build lại module đó riêng: gradlew :fabric-1.21.6:build (ví dụ).

Muốn build RIÊNG 1 module cụ thể (nhanh hơn, để test thử):
    gradlew :fabric-1.21.1:build
    gradlew :forge-1.20.1:build
    gradlew :neoforge-1.21.1:build
    gradlew :plugin:build
